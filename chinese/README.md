# 静心 · 中文实践版

网站按《静心》五个部分组织，并保留“按书阅读”和“按练习方式快速寻找”两条入口。

- 第一、二、四、五部分的阅读卡均按书中对应章节单独整理，不使用重复的通用正文。
- 第三部分保留书中 19 个方法章节，并把扩展练习明确放在章节之后。
- 首页提供“重点静心”快速入口：9 个主动静心、6 个被动静心。
- 实践页面继续采用“步骤 → 对应图片 → 下一步”，并保留原有音频、视频、图片、PDF 相对路径。
- 移动端底部入口：今天 / 重点 / 找方法 / 按书读。


## 部署目录
中文 HTML 位于 `/chinese/`。共享资源位于上一层：`/css/`、`/js/`、`/images/`、`/mp3/`、`/mp4/`、`/pdf/`。因此中文页面统一使用 `../` 访问这些资源。中文页面之间的链接仍保持同目录相对链接。
